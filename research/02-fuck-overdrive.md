# SS/BS Fuck Replacement — LV2 Plugin Research Report

Sources cloned to `/tmp/research-fuck/`: Guitarix (brummer10), CollisionDrive (brummer10), GxAxisFace.lv2 (brummer10), GxFenderizer.lv2 (brummer10), Freaked/Freakclip (pjotrompet). DSP code read for all five candidates. The three `gx_*` plugins on the pi-Stomp (supersonic, AxisFace, fenderizer) ship as standalone LV2s in brummer10's `GxPlugins.lv2` family, not from the main Guitarix tree — but their DSP is faust-generated and traceable.

## Ranking (best → worst fit for the Fuck)

### 1. `gx_supersonic.lv2` — "Push Pull 6L6" power-amp clipper
The strongest sonic analog to the Fuck, ironically because it's modeling the **op-amp + push-pull output stage of a Fender SuperSonic amp**, not a pedal. DSP: `faust/supersonic.dsp` + `gx_head/engine/tabels/supersonic_table.h`. The signal hits a 5th-order IIR prefilter then a **piecewise-linear clipper with two distinct lookup tables — `supersonic_table` (positive half, saturates at +0.474) and `supersonic_neg_table` (negative half, saturates at −0.467)** selected via `signbit()`. The positive/negative tables are *not* mirror images, so the clipping is **asymmetrical → rich even harmonics → that "gnarly, blown-out but chord-articulate" character** the Fuck is loved for. Op-amp-style saturation, not transistor fuzz. Parameters are just `Pregain`/`Gain` (slew-limited via `fRec1`/`fRec2` one-pole smoothers), so it stays articulate under heavy gain — chords don't turn to mush. **No bias-collapse control** (the one missing Fuck feature), and it's a power-amp model not a dirt pedal, so the midrange hump and low-end tighten are different. But tonally it's the closest of the five to "op-amp drive that stays clear when blown out."

### 2. `gx_AxisFace.lv2` — "Axis Face Silicon" (Fuzz Face variant)
From `dsp/AxisFace.cc` (faust-generated). It's a silicon Fuzz Face derivative — **single-ended NPN transistor fuzz, not op-amp**. Clipping is a symmetric `symclip()` table (`clip.data` runs 0→0.527 monotonically and is sign-copied, so positive and negative halves are identical) → **mostly odd harmonics, less chord articulation** than the Fuck's asymmetric op-amp clip. Three controls: `ATTACK`, `SMOOTH`, `VOLUME` (matching the real Axis Face pedal). The `ATTACK`/`SMOOTH` sliders only retune the tone filter's IIR coefficients (`fRec1`/`fRec2`/`fTemp0` block) — they shape EQ, **not the clipper's operating point**. **No bias control, no collapsing artifact.** Gnarly and aggressive in the right register but it's a vintage fuzz voice, not Fuck-voiced. Code is honest faust-generated analog-style modelling (asymmetric FF clipping would need separate tables, which it doesn't have).

### 3. `CollisionDrive.lv2` — Horizon Devices Precision Drive clone
Honest, well-engineered — `dsp/CollisionDrivesim.dsp` lays out the actual circuit blocks: input buffer (`p1`), clipping amp (`p2`), tone (`p3`), volume (`p4`), plus a real noise gate. **But it is a Tube Screamer derivative, openly acknowledged** (the README and forum posts say "slightly modified Tube Screamer"; `ts9nonlin.cc` is literally generated by `tools/ts9sim.py` and named `ts9table`). The clipper is the classic TS feedback-style nonlinearity applied in a `_ <: _ - nonlin(X2-_) :> _` loop — symmetric-ish op-amp soft clip, **no bias/offset parameter**, no collapse. The `Attack` control is a capacitor selector (0.47µF→0.01µF) that changes the high-pass corner ahead of the clipper — it alters *attack envelope/low-end cleanup*, not the clipper's bias. Sonic signature: tight, middy, articulate, "metal tightener" — the **opposite** of the Fuck's open, blown-out, splatty character. High-quality code, faithful analog modelling, but an **impostor for this use case**: it's the pedal the Fuck was deliberately designed *not* to sound like.

### 4. `gx_fenderizer.lv2` — Fender solid-state amp sim
`dsp/fenderizer.cc` + `fenderizer_table.h` — a **`tubeclip`** waveshaper driven by a 6-pole IIR preamp, with a full BASS/MID/TREBLE/BRIGHT/VOLUME stack. It's a **clean-to-crunch amp model**, not a dirt pedal. Tube-style symmetric soft clip (single `tube_table`, monotonic 0→0.76, sign-copied) → low harmonic-content distortion, polite, "Fender clean channel pushed." No bias control, no gating, no gnarl. Wrong category entirely — it's what you'd put *after* the Fuck, not in its place.

### 5. `Freakclip.lv2` — "Clipped Filter" (Freaked bundle)
The weakest fit and the lowest code quality. `Faustsrc/FreakClip.dsp` is ~15 lines: `Distort = _/Drive : ((_*Delay:_@1:_) - _~_)` — that's a **one-pole high-pass difference** (a fixed 0.996 feedback subtracted from a unit-delayed input), then a hard `Thresh = max(-clip, min(clip, x))` **hard clipper** with a `Clip` threshold slider. No analog modelling, no op-amp, no transistor, no bias — just `min/max` brickwall clipping with a DC blocker. The "Drive" is a linear gain; "Clip" sets the brickwall level. It produces a buzzy, static, intermodulation-heavy distortion that **destroys chord clarity** (hard clipping → all harmonics, sum/difference products everywhere). The author's own README calls it "a Distortion based on Filter techniques" — it's a granular/reverb experiment (the bundle's other plugins are `FreakTail` reverb and `Granulator`), not a voiced drive pedal. **Avoid for the Fuck slot.**

## Recommendation
**`gx_supersonic.lv2`** is the only candidate with the Fuck's core voice: op-amp-style **asymmetric** saturation that stays articulate under heavy gain. Pair it with a gentle high-pass ahead (the Fuck's input stage rolls low end) and a touch of post-EQ to mimic its midrange bump. You will not get the bias-collapse gating artefact from any of these five — that's the one Fuck signature you'd have to live without, or approximate by automating the supersonic `Gain`/`Pregain` with a slow envelope. CollisionDrive is the best *engineered* plugin of the set but is tonally the wrong pedal (a TS, not a Fuck).
