# LV2 Whammy Replacement — Research Report

## Summary / Ranking

| Rank | Plugin | Algorithm | Treadle (continuous pitch CV)? | Mono pitch tracker? | Whammy-closeness |
|---|---|---|---|---|---|
| **1** | **`mod-superwhammy.lv2`** | Phase vocoder (FFTW + armadillo, phase-unwrapped overlap-add + resample) | **Yes** — `Step` 0..1 maps across `First`→`Last` (-12..+24 semitones), 100 ms smoothed | No (no fundamental detector) | **Best of the installed set** |
| 2 | `mod-drop.lv2` | Same phase vocoder engine as SuperWhammy | Yes — `Step` (-12..0 semitones, but can be set across its range) | No | Close, but voiced as a drop-tuner, no dry blend, narrower down-range |
| 3 | `MaPitchshift.lv2` | Max gen~ granular/delay-line (4 cosine-windowed grains, phasor-driven) | Yes — `ratio` 0.25..4.0 (±2 oct), automatable | No | Continuous control + ±2 oct, but granular not PSOLA; chunky on chords |
| 4 | `am_pitchshift-swh.lv2` | Dual-read-pointer delay-line granular with sine crossfade | Yes — `pitch` 0.25..4.0 multiplier | No | Cheap, glitchy-on-chords (Whammy-like glitch, but unintentional), small latency |
| 5 | `Pitchotto.lv2` | Max gen~ dual granular shifter (2 voices, filter, blur) | Yes — `ratio1`/`ratio2` 0.5..2 (±1 oct), `mix` | No | Designed for shoegaze shimmer, not Whammy dives; ±1 oct only |

**Winner:** `mod-superwhammy.lv2`. It is the only installed plugin that combines a **continuous expression treadle** (`Step`) with configurable octave endpoints (up to +2 octaves), a dry/clean blend, and a real pitch-shift DSP (phase vocoder) that produces the smooth glissando the Whammy is known for.

## Per-plugin analysis

### 1. `mod-superwhammy.lv2` — Super Whammy (MOD Audio) — **RECOMMENDED**
Source: `github.com/moddevices/mod-pitchshifter`, `SuperWhammy/` + `Shared_files/`. DSP is a textbook **phase vocoder**: `PSAnalysis` does Hann-windowed FFT (`fftwf_plan_dft_r2c_1d`), phase unwrapping (`d_phi_wrapped = d_phi_prime - 2π·floor((d_phi_prime+π)/2π)`, `omega_true`), and `PSSinthesis` resynthesizes with a time-stretched synthesis hop `hops = round(hopa·2^(s/12))` then linear-interpolates back to `hopa` samples (`PitchShifterClasses.cpp:179`, `:255-263`). Ports (`SuperWhammy.cpp:14`, TTL): `Step` (0..1, the treadle), `First` (-12..+24), `Last` (-12..+24), `Clean` (dry blend 0/1), `Gain`, `Fidelity` (0..3, trades latency vs. quality). The `Step` value is low-pass smoothed (`alpha = 0.01^(bufdur/0.1)`, `SuperWhammy.cpp:173`) giving the ~100 ms glide that mimics the treadle. Final pitch `s_ = First + current_s·(Last-First)` (`:176`). **No fundamental detector** — it's pure spectral, so it does NOT track monophonic input the way the Whammy does; on chords it smears (phase vocoder artifact: transient smearing, "metallic" on polyphony) rather than the Whammy's characteristic confusion-glitch. But on single-note lines the glissando is clean and continuous, and the ±2-octave up range with `Clean` blend covers D'Agostino's dive territory. Latency = `nBuffers·n_samples` (Fidelity 1 @ 128 samples ≈ 16 ms). This is the closest match in the installed set.

### 2. `mod-drop.lv2` — Drop (MOD Audio)
Same `PSAnalysis`/`PSSinthesis` phase-vocoder engine as SuperWhammy (`Drop.cpp:30-32`). Ports: `Step` (-12..0 semitones directly, no First/Last endpoints), `Gain`, `Fidelity` (0..2). No `Clean`/dry blend — output is fully wet. It is voiced as a drop-tuning pedal (lower only by default), but `Step` is a continuous control so it can sweep. Lacks SuperWhammy's octave-up range and dry blend; use only if you specifically want a fixed-down dive with no clean blend.

### 3. `MaPitchshift.lv2` (DISTRHO/DPF, Max gen~ example)
Source: `github.com/DISTRHO/DPF-Plugins`, `plugins/pitchshift/` — auto-generated from `pitchshift.gendsp`. A **granular delay-line shifter**: 4 grains, each reading from an 88200-sample delay via `read_linear`, windowed by `cos²` (`gen_exported.cpp:134-135,166-176`), grain rate from a phasor. Params: `ratio` (0.25..4 = ±2 oct, **automatable** per `DistrhoPluginMaxGen.cpp:53`), `window` (0.1..1000 ms grain size), `blur` (0..0.25 — noise jitter on grain positions, smearing transients), `xfade` (dry/wet). Mono in → stereo out. **No pitch tracker, no PSOLA** — grains are free-running, not period-locked, so on monophonic input it's smooth but lacks the Whammy's "intelligent" tracking; chords produce granular smearing. The `ratio` is fully continuous and covers ±2 oct, so it's a usable treadle-driven shifter with a different (grainier) character than SuperWhammy. Good fallback if the phase vocoder's CPU cost is too high.

### 4. `am_pitchshift-swh.lv2` — Steve Harris AM Pitchshifter
Source: `github.com/swh/lv2`, `plugins/am_pitchshift-swh.lv2/plugin.xml`. Classic **dual-read-pointer delay-line** granular shifter: one write head, two read heads offset by `delay_ofs`, crossfaded by `sine(distance)` (`plugin.xml` run callback). Cubic-interpolated reads. `pitch` port is a 0.25..4.0 multiplier (±2 oct, logarithmic, **continuous/treadle-able**), `latency` = `delay_ofs/2` (small, a few ms). No pitch tracker, no PSOLA. The author's own description: "based on the mechanism of a mechanical pitchshifter I saw in the Gemeentemuseum." It is the cheap-and-glitchy approach — on chords it stutters as the crossfade hits the discontinuity, which is *coincidentally* Whammy-like in character but not by design. Latency is the lowest of the set. Use as a low-CPU, intentionally lo-fi dive effect.

### 5. `Pitchotto.lv2` (SHIRO-Plugins, Nino de Wit)
Source: `github.com/ninodewit/SHIRO-Plugins` @ commit `60a678c`, `plugins/pitchotto/` — Max gen~. A **dual-voice granular shifter**: two independent delay-line grain engines (`m_delay_10`, `m_delay_11`), each with its own `ratio` (0.5..2 = ±1 octave only) and `delay`, plus `mix`, `cutoff` (post-filter), `blur`. Mono in → mono out. Clearly designed for the shoegaze "detuned double" shimmer (two slightly different shifts mixed), not for a single dramatic dive. The ±1-octave limit undershoots the Whammy's ±2-octave range, and there's no pitch tracking. Pretty for ambient texturing; not the Whammy sound.

### 6. `tap-pitch.lv2` — TAP Pitch (Tom Szilagyi)
Source: `github.com/moddevices/tap-lv2`, `pitch/tap_pitch.c`. **Not actually a pitch shifter** — it's a 3-tap delay-line **phase modulator**: a fixed `PM_FREQ = 6 Hz` cosine modulates three read-pointer offsets (`tap_pitch.c:223-256`), each tap is amplitude-windowed by a 90°-shifted cosine, and the dry signal is summed at the "depth" point (`:276`). `semitone` (-12..+12) sets the modulation *depth* via `rate = 100·(2^(st/12)-1)` (`:210`), `Rate` (-50..+100) sets it directly when semitone=0. This produces a **vibrato/chorus/doubler**, not a sustained pitch shift — the pitch wobbles around the input at 6 Hz. There is no treadle-able static shift. **Do not use this for the Whammy role.**

## Bonus finding (not in your candidate list)
While locating the MOD packages I found **`dm-Whammy.lv2`** (`github.com/davemollen/dm-Whammy`, Rust) in the `mod-plugin-builder` package set. Its architecture is the **closest to a real Whammy of anything I read**: a `PitchDetector` (zero-crossing on a 20 Hz one-pole-filtered signal, `pitch_detector.rs:29-43`) feeds a 4-voice **PSOLA-like synchronous granular shifter** where the grain frequency is derived from the detected fundamental (`grains.rs:46-49` `get_grain_freq`), grain windows are period-locked (`grain.rs:38 window_size = freq⁻¹·1000`), and `pitch` (-24..+24 semitones) maps to grain read speed with 50 ms linear smoothing (`params.rs:14-17`) — i.e. real monophonic tracking + treadle glissando, exactly the Whammy signature. The pitch detector is admittedly crude (the code has a `TODO: replace this with a better pitch detector`), but it's the right design. If `dm-Whammy.lv2` is or can be installed on the pi-Stomp, it is the truest Whammy clone of the lot — closer than `mod-superwhammy` on the "monophonic intelligent" criterion, though SuperWhammy's phase vocoder is smoother on clean single notes.

## Recommendation for the D'Agostino / Cymbals Eat Guitars sound
Use **`mod-superwhammy.lv2`** with `First`=0, `Last`=+24 (or +12 for the more common +1-oct dive), `Clean`=0 (full wet), `Fidelity`=1 or 2, and map your expression pedal MIDI CC to `Step`. For the chord-confusion glitch passages, ride `Fidelity` down to 0 (shorter window → more smear/glitch). If you want the truer "intelligent monophonic" tracking character and can install it, switch to `dm-Whammy.lv2`. Avoid `tap-pitch.lv2` for this role entirely.
