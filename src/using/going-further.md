# Going Further

The pi-Stomp is a Debian machine with a real-time kernel and a JACK server on it, and MOD is one of the things that can use them. These pages cover the rest.

None of it is needed for a working guitar rig. All of it is things the hardware turns out to be able to do.

- [Neural Amp Modeler]({{ '/using/nam/' | url }}) — loading captures, and what they cost in CPU
- [Hosting Synths & Samplers]({{ '/using/synths/' | url }}) — the pedal as a MIDI sound module
- [Ethernet Audio (alpha)]({{ '/using/ethernet-audio/' | url }}) — multichannel audio over the network port
- [Other Software]({{ '/using/other-software/' | url }}) — running non-MOD JACK applications alongside, or instead of, the stock stack
