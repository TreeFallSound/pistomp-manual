# In the Browser

MOD-UI at [pistomp.local](http://pistomp.local) is where you build. Drag plugins onto a canvas, wire them together, save the result as a pedalboard, and the pi-Stomp plays it back with nothing plugged into it.

You need the browser to build a board and to bind controls. You don't need it to use one.

- [MOD-UI]({{ '/using/mod-ui/' | url }}) — the interface itself: canvas, banks, snapshots, MIDI learn
- [Pedalboards]({{ '/using/pedalboards/' | url }}) — saving, organising, and sharing them
- [Plugins & Effects]({{ '/using/plugins/' | url }}) — what ships, and how to install more
