# Using pi-Stomp

The Using pages document the **pi-Stomp v3** (Pi 5, 4 footswitches, 3 tweak encoders, 2.8" color TFT). v2 (Pi 3/4, up to 5 footswitches, 1 encoder, color TFT) is supported by the same software with a different hardware class — see the inline v2 callouts on each page for what differs, and the [v2 Core wiki](https://www.treefallsound.com/wiki/doku.php?id=pi-stomp_core) for build-specific details.
